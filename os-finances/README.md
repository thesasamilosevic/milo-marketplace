# OS+ Finances Plugin

Extends the OS+ Finances package. Tools for calm, deliberate spending decisions.

## Components

| Skill | Command | What it does |
| --- | --- | --- |
| Shopping Strategist | `/os-finances:shopping-strategist` | Researches a purchase with rigor: vets brands, compares options, and returns a quality-first, source-cited verdict. |

## Source

Built from the AI Assets Vault prompt, per the conversion map at
`projects/4.0_PURPOSE/4.4_PRODUCT_&_DISTRIBUTION/ai-assets-skill-conversion-map.md`.
The repo file is the master copy. To tune the skill, edit its `SKILL.md` and recompile the bundle.

## Setup

The skill works best when pointed at the user's own purchase history, consumption framework, and shopping criteria. If those are not connected, it asks for the relevant context or proposes a sensible starter set before researching.
