# OS+ Founder Plugin

Extends the OS+ Founder package. The one-person business engine.

## Components

| Skill | Command | What it does |
| --- | --- | --- |
| Marketing Copy | `/os-founder:marketing-copy` | Models a high-performing ad or email, then writes new copy to the user's product, audience, and tone. |
| AI-Usage SWOT | `/os-founder:swot-analysis` | A SWOT of how the user is using AI in their role, with five practical use cases to improve. |
| SOT Analysis | `/os-founder:sot-analysis` | Reads where a market or role is heading, then cross-reads it against strengths and opportunities into a ranked list of what to sharpen and what to acquire. |

## Source

Built from the AI Assets Vault prompts, per the conversion map at
`projects/4.0_PURPOSE/4.4_PRODUCT_&_DISTRIBUTION/ai-assets-skill-conversion-map.md`.

SOT Analysis is the exception. It is adapted from the SOT Analysis worksheet in the
Paper Napkin Wisdom 2025 Q2 Simple Planner, page 19, rather than from a Vault prompt.
It is not a variant of the SWOT skill. Three boxes instead of four, and it drops
weaknesses and threats deliberately so every box points toward something.
The repo file is the master copy. To tune a skill, edit its `SKILL.md` and recompile the bundle.
